# AegisVPN — Android app

Real WireGuard-based VPN client for Android. The tunnel is **wireguard-go**
compiled by **gomobile** into an AAR (`aegislib`); Android only supplies the
TUN file descriptor from `VpnService` — there is no mock or userspace shim.

## Architecture

```
┌─────────────────────────────────────────────────────────────────────┐
│ MainActivity (Jetpack Compose, Material3, dark navy + teal #17C7BD) │
│   ├─ HomeScreen      big circular connect button, rx/tx/duration    │
│   ├─ ServerListScreen  OkHttp GET <coord>/v1/nodes, badges, load    │
│   └─ SettingsScreen    kill-switch link, threat, split, obfs, ...   │
└───────────────┬─────────────────────────────────────────────────────┘
                │ intent extras (wg-quick text + options)
                ▼
┌─────────────────────────────────────────────────────────────────────┐
│ AegisVpnService (android.net.VpnService, specialUse FGS)            │
│  1. parse wg-quick (Address/DNS/MTU/AllowedIPs)                     │
│  2. Builder: addAddress/addRoute(0.0.0.0/0 + ::/0)/addDnsServer/    │
│     setMtu/setSession/addDisallowedApplication/setBlocking(false)   │
│  3. establish()  ──────────────►  tun fd (ParcelFileDescriptor)     │
│  4. aegislib.Start(fd.toLong(), wgConfig, obfs, obfsKey)            │
│  5. poll aegislib.StatusJSON() → VpnStateBus (rx/tx/handshake)      │
└───────────────┬─────────────────────────────────────────────────────┘
                │ gomobile JNI (package aegislib)
                ▼
┌─────────────────────────────────────────────────────────────────────┐
│ engine/cmd/aegislib (Go, wireguard-go)                              │
│   Start(fd int64, wgConfig string, obfsEnabled bool, obfsKey string)│
│   Stop() / StatusJSON() / Version()                                 │
└─────────────────────────────────────────────────────────────────────┘
```

Division of ownership per `docs/PROTOCOL.md`: the **Android side owns
routes/DNS** via `VpnService.Builder`; the **Go side owns the WireGuard
device** (`tun.CreateTUNFromFile`). Profiles are wg-quick text with the
AegisVPN extensions (`AegisObfs`, `AegisObfsKey`).

Client identity: an X25519 keypair is generated **on device** (RFC 7748 ladder
in `ProfileStore.kt`, validated against the RFC 7748 §6.1 test vectors) and
stored in `EncryptedSharedPreferences`. The private key never leaves the
phone; selecting a node in the server list composes the wg-quick profile from
the node's `pubkey`/`host`/`port` plus that keypair.

## Build prerequisites

* **JDK 17**
* **Android SDK**, platform 35 (Android Studio Ladybug or newer has it)
* **NDK r27** — `sdkmanager "ndk;27.0.12077973"` (gomobile needs the NDK)
* **Go 1.22+** and **gomobile** (installed automatically by the script)
* Gradle 8.9 — the script bootstraps the wrapper for you

## Build

```bash
cd AegisVPN
./scripts/build-android.sh
```

The script:

1. checks `ANDROID_HOME`/NDK,
2. installs gomobile if missing and runs `gomobile init`,
3. builds the binding:
   `cd engine && gomobile bind -target=android -androidapi 24 -o ../android/app/libs/aegis.aar ./cmd/aegislib`,
4. regenerates `gradle-wrapper.jar` if absent,
5. runs `./gradlew --no-daemon assembleRelease`,
6. copies the APK to **`dist/AegisVPN.apk`** and prints the path.

## Signing

Release signing reads the environment:

```bash
export AEGIS_KEYSTORE=/path/to/aegis-release.jks
export AEGIS_KEYSTORE_PASSWORD='***'
export AEGIS_KEY_ALIAS=aegisvpn
export AEGIS_KEY_PASSWORD='***'
./scripts/build-android.sh
```

Create a keystore with:

```bash
keytool -genkeypair -v -keystore aegis-release.jks -alias aegisvpn \
  -keyalg RSA -keysize 4096 -validity 10950
```

When the env vars are unset, `app/build.gradle.kts` falls back to the debug
signing config so `assembleRelease` always produces an installable APK. Debug
signed builds are for development only — never distribute them.

## Operational notes (honest limits)

* **Kill switch** — third-party Android apps cannot add firewall rules without
  root. The supported mechanism is the system's *Always-on VPN* +
  *Block connections without VPN*; `SettingsScreen` deep-links to
  `Settings.ACTION_VPN_SETTINGS`.
* **UDP socket protection** — official wireguard-android calls
  `VpnService.protect()` from Go through a JNI back-call. The current
  `aegislib` surface (`Start/Stop/StatusJSON/Version`) has no such back-call
  yet; the service uses `Builder.setUnderlyingNetworks(null)` and documents a
  `ProtectFd` hook as the production follow-up in `AegisVpnService.kt`.
* **Foreground service** — declared as `specialUse` with
  `PROPERTY_SPECIAL_USE_FGS_SUBTYPE = "vpn"` per targetSdk 35 rules.
